# نشر Render المجاني — نسخة تجربة عبر HTTP

هذا الملف يشرح ملف `render.yaml` الافتراضي المخصص للتجربة فقط. لا يستخدم هذا الملف Reverb أو WebSocket أو Redis أو Horizon أو Scheduler أو Meilisearch. يحتفظ `render.production.yaml` بمخطط الإنتاج الكامل ولا يجب استيراده للحساب المجاني.

## ما سينشئه Blueprint

| المورد | الخطة | الاستخدام في التجربة |
|---|---:|---|
| `mazad-trial-api` | Free | Laravel API عامة عبر HTTP/HTTPS، تستعمل REST وإعادة جلب البيانات فقط. |
| `mazad-trial-postgres` | Free | بيانات تجربة مؤقتة لـLaravel. |

تسمح Render بخدمات Web وPostgres مجانية، لكن بقية أنواع الخدمات لا تدعم الخطة المجانية. خدمة الويب المجانية تتوقف بعد 15 دقيقة من الخمول وتستيقظ عند الطلب التالي، وقد يستغرق ذلك نحو دقيقة. كما أن قاعدة Postgres المجانية سعتها 1 GB وتنتهي بعد 30 يوماً، ثم يحذف محتواها بعد فترة السماح إن لم تُرقَّ. [1]

> لا تستخدم هذه النسخة للدفعات الحقيقية أو مزادات تجارية أو بيانات لا يمكن فقدها.

## الخدمات المستبعدة عمداً

| خدمة الإنتاج | حالة نسخة التجربة | الأثر |
|---|---|---|
| Reverb / WebSocket | مستبعدة | لا توجد تحديثات لحظية؛ تعيد الواجهة جلب السعر والسجل عند الطلب. |
| Horizon وScheduler | مستبعدان | لا يوجد تشغيل خلفي موثوق لبدء/إغلاق المزادات أو إرسال jobs. |
| Redis / Key Value | مستبعد | تستخدم Laravel جلسات وcache قاعدة البيانات، ولا توجد قائمة jobs دائمة. |
| Meilisearch | مستبعد | يعتمد البحث على محرك قاعدة بيانات Laravel. |
| S3 | مستبعد | الوسائط التي تُرفع محلياً مؤقتة وتُفقد عند إعادة النشر أو الاستيقاظ. |
| مزود الدفع والشحن | غير مهيأ | لا توجد دفعات أو شحنات حقيقية. |

## الاستيراد في Render

بعد ربط GitHub، أنشئ Blueprint من المستودع `same7egypt-pixel/mazad` والفرع `main`. سيقرأ Render ملف `render.yaml`، ثم اختر **Free** للخدمتين عند ظهور المراجعة. أدخل القيم المطلوبة فقط من لوحة Render؛ لا تحفظ الأسرار في Git:

| المتغير | ما يُدخل |
|---|---|
| `APP_KEY` | ناتج `php artisan key:generate --show` يبدأ بـ`base64:`. |
| `APP_URL` | نطاق خدمة API الذي ستنشئه Render، بصيغة `https://...onrender.com`. |
| `FRONTEND_URL` | نطاق واجهة Marketplace الحالية أو نطاقها اللاحق. |
| `CORS_ALLOWED_ORIGINS` | أصل الواجهة فقط، بلا مسار. |
| `SANCTUM_STATEFUL_DOMAINS` | مضيف الواجهة وAPI، بلا `https://`. |

بعد نجاح النشر، افتح `/up` على نطاق API. لا تربط `VITE_LARAVEL_API_BASE_URL` بالواجهة المنشورة إلا بعد نجاح `/up` واختبار CORS وتسجيل مستخدم تجريبي.

## حدود لا يمكن إخفاؤها

لا تُعامل النسخة المجانية كبيئة إنتاج: لا تتوفر أقراص دائمة، وقد تعيد Render تشغيل خدمة الويب في أي وقت، ولا تضمن قاعدة البيانات المجانية نسخاً احتياطية. [1] تستمر واجهة Marketplace المنشورة في استخدام بيانات العرض الموسومة إلى أن يُضبط عنوان Laravel الحقيقي وتنجح اختبارات الربط الخارجي.
