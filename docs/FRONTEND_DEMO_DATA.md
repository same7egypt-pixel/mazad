# بيانات العرض المؤقتة للواجهة

توجد بيانات العرض المؤقتة في `client/src/data/marketplaceDemo.ts`. وهي موجودة لتقديم تجربة مرئية مكتملة أثناء عدم وجود عنوان Laravel API متاح لمعاينة الويب. لا تمثل هذه البيانات منتجات أو مزايدات أو طلبات أو أرصدة حقيقية، وتُظهر الصفحات شارة **بيانات عرض مؤقتة** حيث يلزم.

لا يتضمن المصدر أي مراجعات أو تقييمات أو شهادات مستخدمين، سواء كانت موجبة أو سالبة. كما أن تفاعلات الحفظ والمزايدة في الواجهة تعطي رسالة توضيحية ولا تنفذ عملية تجارية أو مالية.

| واجهة العرض | المصدر المؤقت | البديل الحي المطلوب |
|---|---|---|
| بطاقات الاستكشاف | `demoAuctionLots` | `GET /api/auctions` أو `GET /api/listings/search` مع ترويسة `X-Marketplace-Country` رقمية |
| تفاصيل المزاد وسجل المزايدة | `getDemoAuction` و`demoBidActivity` | `GET /api/auctions/{auction}` و`GET /api/auctions/{auction}/bids` |
| اختيار الدولة | `demoCountryOptions` | `GET /api/marketplaces/countries` ثم تخزين `id` وإرساله في ترويسة السياق |
| الحساب والطلب والمحفظة والإشعارات | `demoAccountSnapshot` | العقود المحمية للطلبات والمحافظ والإشعارات بعد توفير مسار Laravel مع Sanctum |

عند توفر عنوان API قابل للوصول من المتصفح، تُستبدل الاستيرادات من هذا المصدر بمحولات API ذات أنواع مقابلة، مع الإبقاء على المكونات والواجهات كما هي قدر الإمكان.
